QR CODE

Once this project is deployed (GitHub Pages, Netlify or Vercel), its HTTPS URL can be turned into a QR code. Scanning the printed code opens this page directly on the phone. The code below is generated live for the URL in the field.

Augmented Reality

Scan to awaken the artifact

Use Chrome on an ARCore-capable Android phone.

This URL does not start with https:// – WebXR AR will not start from it. Generate the code from your deployed HTTPS address.

Generate it yourself

Python (creates a print-ready PNG):

pip install "qrcode[pil]"
python qr-generator.py https://your-name.github.io/WebXR-AR/

JavaScript (in a browser, using qrcode-generator):

const qr = qrcode(0, 'H');   // auto size, high error correction
qr.addData('https://your-name.github.io/WebXR-AR/');
qr.make();
document.body.innerHTML = qr.createSvgTag({ cellSize: 8, margin: 4 });
